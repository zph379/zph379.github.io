# AllTact Fin Ray: A Compliant Robot Gripper with Omni-Directional Tactile Sensing

## 1. 论文链接

https://arxiv.org/abs/2504.18064

## 2. 研究问题

这篇论文主要研究机器人夹爪如何获得更加全面的触觉感知能力。

传统的部分柔性夹爪虽然能够适应不同形状的物体，但在触觉感知方面存在一些不足：

- 只能感知特定区域的接触。
- 难以感知来自不同方向的碰撞。
- 难以准确获取物体与夹爪之间的接触几何信息。

因此，作者希望设计一种既具有柔顺性，又能够实现全方向触觉感知和局部接触几何重建的机器人夹爪。

## 3. 核心方法

作者提出了 AllTact Fin Ray 夹爪，将柔性机械结构与视觉触觉传感结合起来。

### 3.1 机械结构

主要由以下部分组成：

- Fin Ray 柔性手指结构
- 透明弹性硅胶
- 半透明接触层
- 摄像头
- 白色 LED 光源
- 表面标记点（Markers）

摄像头安装在手指底部，通过观察硅胶结构和标记点的变化，获取接触信息。

### 3.2 全局形变重建

通过摄像头获取图像，利用图像边缘特征、针孔相机模型和空间几何约束，重建整个手指的三维形变。

### 3.3 局部接触几何重建

当物体接触手指时，硅胶局部发生形变，图像亮度也会发生变化。

作者通过标记点追踪，从预先录制的视频中动态寻找合适的参考图像，再根据亮度变化估计局部接触深度，最终重建接触区域的三维几何信息。

### 3.4 全方向接触检测

通过追踪手指表面的标记点，计算标记点的位置变化，从而判断是否发生接触，以及接触的大致方向。

同时，作者使用多层感知机（MLP）预测接触力的大小。

## 4. 创新与结果

### 主要创新

1. 将 Fin Ray 柔性结构与视觉触觉传感相结合。
2. 实现手指全局形变和局部接触几何的重建。
3. 通过动态参考图像解决全局形变造成的亮度变化问题。
4. 能够检测来自不同方向的接触，并估计接触力。

### 主要实验结果

- 接触位置平均误差：0.814 mm。
- 接触方向分类准确率：98.1%。
- X 方向力估计平均误差：0.244 N。
- Y 方向力估计平均误差：0.162 N。
- 在大部分手指区域，全方向接触检测阈值低于 2 N。

### 方法局限与挑战

- 手指尖端附近的接触定位误差会增大。
- 系统依赖摄像头、图像处理和标记点追踪。
- 柔性硅胶结构的耐久性仍有改进空间。
